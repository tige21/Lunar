# Lunar Sleep App - Quick Start Guide\n\n## 🚀 Getting Started with the Theme System\n\n### 1. Install Dependencies\n\nRun the setup script to install all necessary dependencies:\n\n```bash\n# Make the script executable\nchmod +x scripts/setup-gluestack.sh\n\n# Run the setup\n./scripts/setup-gluestack.sh\n```\n\nOr install manually:\n\n```bash\nnpm install @gluestack-ui/components@^1.0.9 @gluestack-ui/nativewind-utils@^1.0.25 @gluestack-ui/themed@^1.1.55\n```\n\n### 2. Add Required Fonts\n\nDownload and add these font files to `assets/fonts/`:\n- `Inter-Regular.ttf`\n- `Inter-Medium.ttf`\n- `Inter-SemiBold.ttf` \n- `Inter-Bold.ttf`\n\n### 3. Start Development\n\n```bash\nnpm start\n```\n\n## 🎨 Using the Theme System\n\n### Basic Example\n\n```tsx\nimport React from 'react';\nimport { ThemedView, ThemedText, SleepCard } from '@/components/ui';\n\nexport function MySleepScreen() {\n  return (\n    <ThemedView style={{ flex: 1, padding: 16 }}>\n      <ThemedText type=\"title\">Sleep Dashboard</ThemedText>\n      \n      <SleepCard\n        title=\"Total Sleep\"\n        value=\"7h 42m\"\n        subtitle=\"+23 min from average\"\n        trend=\"up\"\n        sleepStage=\"deep\"\n      />\n    </ThemedView>\n  );\n}\n```\n\n### Key Components\n\n1. **ThemedView** - Container with sleep-optimized backgrounds\n2. **ThemedText** - Typography system for health data\n3. **SleepCard** - Metric cards with sleep stage theming\n4. **SleepProgressBar** - Progress indicators for sleep stages\n5. **ThemedButton** - Action buttons with sleep-specific variants\n\n### Sleep Stage Colors\n\n- **Deep Sleep**: `#1E1B3C` (Dark purple)\n- **REM Sleep**: `#3B1A78` (Medium purple)\n- **Light Sleep**: `#4C1D95` (Light purple)\n- **Wake**: `#EA580C` (Warm orange)\n\n## 📱 Testing\n\nUse the example component to test the theme:\n\n```tsx\nimport { SleepDashboardExample } from '@/components/examples/SleepDashboardExample';\n\n// Add to any screen to see the theme in action\n<SleepDashboardExample />\n```\n\n## 🌙 Theme Features\n\n✅ **Sleep-optimized colors** - Calming purples and warm oranges\n✅ **Automatic dark/light mode** - Based on system preferences\n✅ **Typography system** - Optimized for health data display\n✅ **Sleep stage visualization** - Color-coded progress bars and cards\n✅ **Accessible design** - WCAG AA compliance\n✅ **Responsive components** - Works on all screen sizes\n\n## 🔧 Configuration Files\n\nKey files that were set up:\n\n- `components/gluestack-ui-config.tsx` - Theme configuration\n- `components/providers/LunarThemeProvider.tsx` - Theme provider\n- `tailwind.config.js` - Extended color palette\n- `constants/Colors.ts` - Sleep-optimized color definitions\n- `babel.config.js` - NativeWind configuration\n- `nativewind-env.d.ts` - TypeScript declarations\n\n## 📚 Documentation\n\nFor detailed documentation, see:\n- `THEME_SYSTEM.md` - Complete theme system documentation\n- `components/examples/` - Usage examples\n- `components/ui/` - Individual component files\n\n## 🐛 Troubleshooting\n\n### Fonts not loading?\n- Ensure Inter font files are in `assets/fonts/`\n- Check that font names match exactly in the code\n- Restart the development server\n\n### Colors not showing?\n- Verify NativeWind is properly configured\n- Check that `global.css` is imported in `app/_layout.tsx`\n- Clear Metro cache: `npx expo start --clear`\n\n### TypeScript errors?\n- Ensure `nativewind-env.d.ts` is included in `tsconfig.json`\n- Check that all imports use the correct paths\n- Restart TypeScript server in your editor\n\n## 🎯 Next Steps\n\n1. **Customize colors** in `constants/Colors.ts`\n2. **Add new components** following the existing patterns\n3. **Integrate with your sleep data** API\n4. **Test accessibility** with screen readers\n5. **Add animations** for smooth transitions\n\n---\n\n*Happy coding!
