# Lunar Sleep App - Theme System Documentation\n\nThis document outlines the complete theme system implementation for the Lunar sleep analysis app, built with Gluestack UI v2 and optimized for sleep tracking use cases.\n\n## Overview\n\nThe Lunar theme system provides:\n- **Sleep-optimized color palette** with calming deep purples and warm sunrise colors\n- **Responsive dark/light mode** with automatic switching\n- **Sleep stage visualization** with dedicated color coding\n- **Typography optimized** for health data display\n- **Accessible design** with proper contrast ratios\n\n## Color variant=\"default\" />     // Standard background\n<ThemedView variant=\"surface\" />     // Elevated surface\n<ThemedView variant=\"card\" />        // Card with shadow\n<ThemedView variant=\"sleep-surface\" /> // Sleep-themed surface\n```\n\n### ThemedText\nTypography system optimized for health data:\n\n```tsx\n<ThemedText type=\"title\" />      // Page titles (32px, bold)\n<ThemedText type=\"heading\" />    // Section headers (24px, semibold)\n<ThemedText type=\"subtitle\" />   // Subsections (20px, semibold)\n<ThemedText type=\"default\" />    // Body text (16px, regular)\n<ThemedText type=\"caption\" />    // Small labels (12px, uppercase)\n<ThemedText type=\"sleep-data\" />  // Sleep metrics (28px, monospace)\n```\n\n### ThemedButton\nAction buttons with sleep-specific styling:\n\n```tsx\n<ThemedButton variant=\"primary\" />      // Main actions\n<ThemedButton variant=\"secondary\" />    // Secondary actions\n<ThemedButton variant=\"outline\" />      // Outlined buttons\n<ThemedButton variant=\"ghost\" />        // Text-only buttons\n<ThemedButton variant=\"sleep-action\" />  // Special sleep actions\n```\n\n### SleepCard\nSpecialized card for displaying sleep metrics:\n\n```tsx\n<SleepCard \n  title=\"Deep Sleep\"\n  value=\"2h 15m\"\n  subtitle=\"Optimal\"\n  trend=\"up\"\n  sleepStage=\"deep\"\n/>\n```\n\n### SleepProgressBar\nProgress indicators with sleep stage theming:\n\n```tsx\n<SleepProgressBar\n  label=\"Deep Sleep\"\n  progress={0.65}\n  sleepStage=\"deep\"\n  showPercentage\n/>\n```\n\n## Typography System\n\n### Font Stack\n- **Inter**: Primary font for UI text (Regular, Medium, SemiBold, Bold)\n- **SpaceMono**: Monospace font for sleep data and metrics\n\n### Type Scale\n```typescript\nfontSize: {\n  '2xs': 10,  // Tiny text\n  'xs': 12,   // Caption text\n  'sm': 14,   // Small text\n  'md': 16,   // Body text (default)\n  'lg': 18,   // Large text\n  'xl': 20,   // Subtitle\n  '2xl': 24,  // Heading\n  '3xl': 30,  // Large heading\n  '4xl': 36,  // Display\n  '5xl': 48,  // Large display\n  '6xl': 60,  // Huge display\n}\n```\n\n## Dark/Light Mode\n\n### Automatic Theme Switching\nThe app Sleep stage colors are distinguishable for colorblind users\n- High contrast mode support\n\n### Typography\n- Scalable fonts support dynamic type sizing\n- Readable line heights and spacing\n- Proper heading hierarchy\n\n## Implementation Notes\n\n### File Structure\n```\ncomponents/\n├── providers/\n│   └── LunarThemeProvider.tsx    # Main theme provider\n├── ui/\n│   ├── ThemedView.tsx            # Enhanced view component\n│   ├── ThemedText.tsx            # Typography component\n│   ├── ThemedButton.tsx          # Button component\n│   ├── SleepCard.tsx             # Sleep metric card\n│ provider loads only necessary components\n- **Optimized Gradients**: Uses shadow effects instead of heavy gradients\n- **Minimal Dependencies**: Only essential Gluestack UI components\n- **Tree Shaking**: Unused theme tokens are removed in production\n\n## Testing the Theme\n\nUse the provided example component to test the theme system:\n\n```tsx\nimport { SleepDashboardExample } from '@/components/examples/SleepDashboardExample';\n\n// Add to your test screen or development setup\n<SleepDashboardExample />\n```\n\n## Customization\n\nTo modify the theme:\n\n1. Update colors in `constants/Colors.ts`\n2. Modify theme tokens in `components/gluestack-ui-config.tsx`\n3. Adjust Tailwind config in `tailwind.config.js`\n4. Test with the example components\n\n## Support\n\nFor questions about the theme system:\n- Check the example components in `/components/examples/`\n- Review the configuration files\n- Test with different color schemes and sleep stages\n\n---\n\n*The Lunar theme system is designed to provide a calming, sleep-optimized user experience while maintaining excellent usability and accessibility standards.*
